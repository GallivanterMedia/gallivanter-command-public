# Gallivanter Command Public Site

This static site is intentionally separate from the private Gallivanter Command application. It provides:

- `/` — public application overview
- `/privacy.html` — privacy policy
- `/terms.html` — terms of service

It contains no credentials, backend code, OAuth client secrets, tokens, or private Command source.

## Intended public domain

`https://command.gallivantermedia.com/`

## Deploy with GitHub Pages

Use a public repository such as `GallivanterMedia/gallivanter-command-public`.

1. Push these static files to `main`.
2. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Wait for the default Pages site to deploy.
5. In **Settings → Pages → Custom domain**, enter `command.gallivantermedia.com` and save **before changing DNS**.
6. In FastHosts Advanced DNS add:
   - Type: `CNAME`
   - Host/name: `command`
   - Target/value: `GallivanterMedia.github.io`
7. Do not alter MX records, nameservers, or existing email records.
8. Verify from PowerShell with `Resolve-DnsName command.gallivantermedia.com`.
9. When available in GitHub Pages settings, enable **Enforce HTTPS**.

DNS propagation can take time.

## Google domain verification

Use Google Search Console to verify ownership of `gallivantermedia.com`. Add the unique TXT record generated by Search Console in FastHosts Advanced DNS. Never copy an example verification token from documentation.

## Google Auth Platform branding values

Once HTTPS is live:

- Application home page: `https://command.gallivantermedia.com/`
- Privacy policy: `https://command.gallivantermedia.com/privacy.html`
- Terms of Service: `https://command.gallivantermedia.com/terms.html`
- Authorized domain: `gallivantermedia.com`

Keep any existing authorized domain still required by the staging OAuth callback until that callback is deliberately changed.

Do not add new OAuth scopes merely to complete branding.

## Security

Never commit:
- OAuth client secrets
- access or refresh tokens
- `.env` files containing secrets
- application encryption keys
- production database details
- private Gallivanter Command source code
